LG Picture Bridge for G6

Connect a rooted 2026 LG G6 running webOS 11 to Home Assistant. MQTT discovery reports HDMI signal presence, input, picture mode, and SDR/HDR10/HLG/Dolby Vision. Version 0.8.1 keeps the normal status view on screen without vertical scrolling. The bridge uses the G6 HDMI services and picture banks; older C9 firmware is no longer supported.

Optional MQTT commands apply picture profiles and HDMI icons without notification dialogs. Commands have correlated results, short expiry, duplicate protection, and context checks. G6 profile examples include Warm 40, updated gamma controls, HDR/HGiG, and Dolby Vision game mappings.

The optional CEC filter uses rules supplied by Home Assistant to block automatic HDMI-device selection. Explicit selection and eARC remain available. It does not block every CEC wake path or support per-device standby blocking. A verified firmware hash, short lease, and rollback watchdog keep unknown firmware and expired policies on LG's normal behavior.

Requirements

  • A rooted G6 with elevated Homebrew Channel
  • A reachable MQTT broker and Home Assistant
  • The pairing and command scripts from the project

Configuration survives app updates. Keep the same device ID when replacing a TV to preserve Home Assistant entities. Homebrew Channel gets updates through the GitHub release feed. Home Assistant YAML is updated separately. Tested on OLED77G6WUA firmware 43.11.73; installing this app does not update TV firmware.
