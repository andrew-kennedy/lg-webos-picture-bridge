LG Picture Bridge

LG Picture Bridge monitors a rooted LG webOS TV's internal video-output and picture-dimension services. It reports SDR, HDR10, HLG, and Dolby Vision transitions to a local Home Assistant webhook so picture-setting automations can be reapplied whenever content changes format.

Version 0.3.0 adds an authenticated local picture-policy API to the registered Luna monitor. It silently targets active or inactive C9 picture banks without notification dialogs and has been tested end-to-end on a 2019 LG C9.

Requirements

  • A rooted LG webOS TV with an elevated Homebrew Channel installation
  • Home Assistant reachable from the TV over the local network
  • The pairing script from the project documentation

No ambient-light capture server is required. Pairing is sent from Home Assistant as application launch parameters, so no webhook URL needs to be typed with the TV remote.
