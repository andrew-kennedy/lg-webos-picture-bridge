LG Picture Bridge

LG Picture Bridge monitors a rooted LG webOS TV's internal video-output and picture-dimension services. It reports SDR, HDR10, HLG, and Dolby Vision transitions to a local Home Assistant MQTT device, including HDMI signal presence, so picture-setting automations can be reapplied whenever content changes format.

Version 0.5 adds opt-in MQTT picture commands with correlated success/error results, short expiry, duplicate protection and context guards. A Home Assistant REST package is no longer necessary. It silently targets active or inactive C9 picture banks without notification dialogs, then asks webOS to refresh the active picture-processing pipeline without cycling modes. It has been tested end-to-end on a 2019 LG C9. Configuration and status use the app's own registered service rather than Homebrew Channel's generic shell-exec API.

Version 0.6 adds an optional Apple TV wake filter for the inspected rooted C9 firmware. It suppresses LG's automatic Apple TV selection when returning to HDMI 3 after native AirPlay. The filter is off by default, uses a removable runtime overlay rather than overwriting firmware, and has an off switch in the app. SIMPLINK and Auto Power Sync stay unchanged. It does not fix the separate first-attempt AirPlay connection timeout after standby.

Requirements

  • A rooted LG webOS TV with an elevated Homebrew Channel installation
  • Home Assistant reachable from the TV over the local network
  • The MQTT configuration script from the project documentation

No ambient-light capture server is required. Configuration is sent from Home Assistant as application launch parameters, so no credentials need to be typed with the TV remote. Settings survive updates. Version 0.5.2 fixes the status screen on older webOS browsers: action buttons stay within the screen and long details scroll with Up/Down. Left/Right selects an action. Optional HTTP commands and legacy webhooks remain supported.
